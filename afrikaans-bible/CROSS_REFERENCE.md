# CROSS_REFERENCE.md — Parallel-passage register

> Verses that recur verbatim (or near-verbatim) elsewhere in Scripture **must use the
> identical Afrikaans rendering** in every location. This file tracks those parallels so
> that when the later passage is reached, the earlier decision can be carried over rather
> than re-litigated.
>
> The **translator's note** for a parallel is written once (normally at the first
> occurrence) and covers every linked verse.

**Status:** ✅ committed · 🟡 provisional · 🔴 open
